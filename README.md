# mongoDB-basics

Project Overview
This project covers basic MongoDB operations using MongoDB Shell ( mongosh ). It includes database setup, CRUD operations, query operators, and a Library System use case.
Tasks Covered
1. Database & Collection Setup
•	Create the studentDB database.
•	Create the students collection.
2. Insert Operations
•	Insert a single document.
•	Insert multiple student documents.
3. Read Operations
•	Retrieve all student documents.
•	Filter and retrieve specific student records.
4. Update Operations
•	Update a single document.
•	Update multiple documents and verify the results.
5. Delete Operations
•	Delete a single document.
•	Delete multiple documents to practice collection manipulation.
6. Query Operators
•	Filter records using comparison operators like $gt and $lt.
•	Implement membership tests using the $in operator.
